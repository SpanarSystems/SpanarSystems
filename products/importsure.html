FAQ

Common questions.

Does ImportSure import the file for me?

The early-access workflow focuses on read-only analysis and produces a safer file for the CRM's native importer.

Does it change CRM data during the scan?

No. The review can use read-only CRM access or a fresh CRM export; nothing is written during analysis.

Which CRM does it support?

The first pilot is designed around HubSpot CSV imports, with broader CRM support planned after validation.
